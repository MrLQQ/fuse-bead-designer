# Contributing

## Bundled template font

The renderer bundles `assets/fonts/NotoSansCJKsc-Regular.otf` from the
[`notofonts/noto-cjk`](https://github.com/notofonts/noto-cjk) repository:
`Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf`.

It is distributed under the SIL Open Font License, Version 1.1. The exact
upstream license text is bundled unchanged as `assets/fonts/OFL.txt`. Keep both
files together when modifying or redistributing the renderer.
