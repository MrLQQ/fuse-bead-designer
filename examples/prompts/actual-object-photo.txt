Source-generation prompt
========================

Use case: product-mockup
Asset type: openly distributable raw evaluation fixture for a craft-pattern conversion task
Primary request: Create an original studio product photograph of exactly one unbranded red low-top canvas sneaker.
Scene/backdrop: plain warm-white seamless studio background, clean and uncluttered.
Subject: one red canvas sneaker only, shown in a clear three-quarter side profile; recognizable red woven canvas upper, matching red tongue, white cotton laces, white rubber toe cap, white rubber sidewall and outsole, small metal eyelets; no logo, label, lettering, decorative emblem, or brand-specific stripe.
Style/medium: photorealistic catalog product photography with real canvas weave, lace fibers, rubber texture, and natural construction seams.
Composition/framing: entire shoe centered, toe pointing left, heel to the right, clear continuous silhouette, generous padding, no cropping.
Lighting/mood: soft diffused studio lighting with a subtle natural grounding shadow.
Color palette: saturated red upper, clean white laces and rubber, warm-white background.
Constraints: original imagery only; exactly one shoe; no person, foot, box, props, text, watermark, logo, extra object, grid, legend, counts, bead art, or final template.
Avoid: floating shoe, dramatic reflections, busy background, recognizable trademark design, illustration or 3D-render appearance.

Deterministic cleanup
=====================

The clean intermediate preserves the source RGB values byte-for-byte for every
occupied pixel. A conservative alpha matte separates the visible shoe from the
studio background and grounding shadow. Foreground evidence comes from the
original image's saturation and value channels, is constrained to the visible
shoe silhouette, and fills enclosed white regions such as the laces, toe cap,
sidewall, and outsole. No image model was used for cleanup and no subject pixel
was repainted.

v0.3 pattern-draft migration
============================

The semantic pattern draft is a lossless four-raster-pixels-per-cell rendering
of the previously committed public compiler matrix. It was created locally and
deterministically; no user image or image-generation call was involved. The
v0.3 compiler keeps the original source above as `--input` and consumes this
separate draft through `--draft-input` with the declared 58 × 29 logical grid.

Verification note
=================

The shoe is fully visible, so no hidden area required reconstruction. The
compiler retains the principal red, warm-white, and tan color blocks. However,
the semantic pattern draft includes design simplification that the
deterministic compiler cannot confirm, so this high-resolution route remains
`review-required`.
