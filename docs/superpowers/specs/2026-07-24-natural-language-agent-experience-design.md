# 自然语言 Agent 体验设计（v0.2.0）

## 目标

用户只需完成两件事：

1. 首次把仓库地址发给 Agent，并批准安装。
2. 后续上传素材图片，用自然语言要求生成拼豆设计图。

安装、依赖检查、图像分类、主体清理、画板选择、确定性编译和文件交付都由 Agent 完成。正常用户文档不要求用户执行 Python 或 Codex CLI 命令。

## 真实边界

- Plugin 或 Skill 不能绕过宿主权限静默自安装。Agent 必须在首次安装时请求授权。
- Codex 当前需要新任务才能稳定加载刚安装的 Skill。安装任务负责完成安装并明确提示用户开启新任务；新任务开始后只使用自然语言。
- 仓库不能保证所有 Agent 宿主都有相同的插件市场、文件目录或图像编辑能力。Codex Plugin 是主路径，独立 Agent Skill 是兼容路径。
- 确定性编译器仍是网格和数量的唯一可信源。图像模型只负责主体识别和语义清理。

## 用户体验

### 首次安装

用户发送：

> 请安装并使用 https://github.com/MrLQQ/fuse-bead-designer。安装过程由你完成，不要让我运行命令。

Codex Agent 在获得授权后内部执行：

```text
codex plugin marketplace add MrLQQ/fuse-bead-designer --ref v0.2.0
codex plugin add fuse-bead-designer@fuse-bead-designer
```

安装成功后，Agent 提示用户开启新任务并上传图片。不把上述命令作为用户操作步骤。

不支持 Codex Plugin 的 Agent 应读取仓库安装协议，下载 Release 中的独立 Skill，并按宿主规则安装；无法确定目标目录或权限时才向用户确认。

### 日常生成

用户上传图片并发送：

> 把这张图生成拼豆设计图，优先使用常规 29×29 拼豆板，并告诉我每种颜色和数量。

Agent 自动完成：

1. 检查素材并识别唯一主体。
2. 区分拼豆成品照片、像素画和高清非像素图。
3. 移除手、工具、桌面、画板、阴影等非主体内容；谨慎处理遮挡。
4. 选择合适的 29 格板组合和通用调色板，或使用用户提供的库存色板。
5. 在内部调用随 Skill 打包的编译器。
6. 检查模板、报告和数量一致性。
7. 直接交付图纸、颜色表、数量和不确定性状态。

只有多主体、关键遮挡、超大画板或用户偏好会实质改变结果时，Agent 才暂停询问。

## 仓库与文档变化

### Marketplace

将仓库 Marketplace 名称从通用的 `personal` 改为 `fuse-bead-designer`，使远程安装选择器稳定为：

```text
fuse-bead-designer@fuse-bead-designer
```

### Agent 安装协议

在仓库根目录增加 `AGENTS.md`，说明：

- 用户给出仓库地址并要求安装时，Agent 应自行完成安装。
- 所有命令是 Agent 内部动作，不应让用户复制执行。
- Codex、其他 Agent Skills 宿主和不支持安装的宿主分别如何处理。
- 安装后如何验证，以及何时要求开启新任务。

### Skill 行为

更新 `SKILL.md`：

- 扩充自然语言触发词，包括“拼豆图纸”“拼豆模板”“像素拼豆”“颜色数量”等中英文表达。
- 明确 Agent 对完整工作流负责。
- 将编译命令标记为内部实现，不作为用户步骤。
- 禁止仅返回命令、要求用户运行脚本，或在已有权限时把依赖处理转交给用户。
- 保留必须询问用户的安全与不确定性边界。

更新 `agents/openai.yaml`，让默认提示直接表达“使用附件生成并交付图纸”，不暴露 Skill 名称或内部命令。

### README

中文 README 首屏按以下顺序组织：

1. 一句话产品价值。
2. 首次安装的自然语言提示。
3. 日常使用的自然语言提示。
4. 四组“原始素材 → 拼豆模板”效果对照：手指遮挡的拼豆成品、被前景物遮挡的普通高清图、真实物体照片、高清非像素插画。
5. 每组示例标明画板尺寸、总豆数和 `verified` 或 `review-required` 状态。
6. 可获得的交付文件和示例图。
7. 工作原理与不确定性边界。
8. 其他 Agent 的兼容说明。
9. 开发者章节中的 CLI、测试和打包命令。

英文 README 使用相同信息架构，作为备选语言。

## 错误处理

- 安装权限被拒绝：说明未发生安装，不声称可继续调用 Skill。
- Plugin 已安装：避免重复添加 Marketplace，确认现有版本并继续。
- 当前任务无法动态加载：明确提示开启新任务，不假装 Skill 已生效。
- 缺少图像能力：对清晰像素图可以继续；涉及主体分离或遮挡时请求更清晰素材或换用具备图像能力的 Agent。
- 编译失败：Agent 读取错误并处理依赖、路径或输入问题；只有需要用户选择或新权限时才询问。

## 验收标准

1. README 的普通用户主路径不包含需要用户执行的命令。
2. 给未安装的 Codex Agent 发送仓库地址和安装意图时，Agent 能识别 Marketplace 与 Plugin 选择器并请求安装授权。
3. 安装后的新任务中，用户只上传图片并使用自然语言，Agent 会内部调用编译器并交付完整产物。
4. Agent 不会把手、桌面和背景计为拼豆；无法确认的补全保持 `review-required`。
5. `pattern.json`、`colors.csv` 和模板数量一致，品牌色号只来自用户提供的色板。
6. Plugin 和独立 Skill 均通过结构校验，并打包为 v0.2.0 Release 附件。
7. README 同时展示四类公开可再分发输入及其真实编译输出，不使用手绘或伪造数量。

## 非目标

- 不建设独立网页应用。
- 不提交公共插件市场审核。
- 不承诺所有第三方 Agent 能在同一任务中动态加载新 Skill。
- 不用自动安装脚本绕过宿主权限或安全确认。
