# 保真与资源归一化设计

## 目标

修复两个根因：

1. 将统一放大的观察网格误当成逻辑网格，导致用豆量按面积倍增。
2. 默认把所有图案压缩到 16 色，导致低频但重要的颜色被静默替换。

## 空间规则

- 对带有精确最近邻证据的输入，寻找所有可以逐字节重建原图的统一整数倍率。
- 选择最大的安全倍率，得到最小语义网格。
- X、Y 必须使用同一倍率；无过渡的纯色图仍视为歧义。
- 报告记录观察尺寸、逻辑尺寸、线性倍率、面积倍率和节省格数。
- 用户明确声明宽高时，以声明为准，不自动折叠。
- 底板数量只在逻辑网格确定后推导。

## 颜色规则

- 默认不限制使用颜色数。
- 只有用户明确传入 `--colors N` 时才执行颜色融合。
- `N` 只要求为正整数，不再限制在 8 到 16。
- 融合前后分别统计颜色数和发生替换的格数。
- 报告分别给出 `grid_fidelity`、`color_fidelity` 和
  `semantic_fidelity`；显式融合不能继续标为颜色完全保真。

## 兼容性

- 保留显式 `color_limit` 调用能力。
- 现有图纸、CSV 和模板格式不变。
- `report.json` 和 `pattern.json.settings` 仅增加字段。
- 不在本次实现 README 装修和完整商业色卡数据库。

## 验收

- 105×102 的精确 3×3 重复图恢复为 35×34，面积倍率为 9。
- 4×4 图案放大到 16×16 时恢复为 4×4，不因存在 2 倍候选而拒绝。
- 非统一 X/Y 倍率和抗锯齿图仍被拒绝。
- 20 色自定义色板默认保留 20 色。
- 显式 `--colors 16` 才压缩为 16 色，并报告减少数量与改动格。
- 21 色、2039 个占格的现有图纸在未指定 `--colors` 时不丢色、不改总数。
